# HW2 · 문제 09: 3자유도 질량·강성행렬과 정적 변위

## 문제

m1=m2=m3=1 kg, k1~k6=2 N/m이다. k1,k2,k3는 각 질량과 벽, k4는 m1–m2, k5는 m2–m3, k6는 m1–m3를 연결한다. (a) M,K, (b) 외력 [1;2;3] N에서 정적 변위를 구한다. 원문의 세 번째 외력 표기는 F2=3 N이나 F3의 오기로 해석한다.

[원본 PDF 2쪽](../../EngComp_HW2.pdf#page=2)

## 풀이

대각 성분은 해당 질량에 연결된 스프링 강성의 합, 비대각 성분은 두 질량 사이 스프링 강성의 음수이다. M=I, K=[6,−2,−2;−2,6,−2;−2,−2,6]이며 Kx=F를 푼다. 운동방정식의 강성행렬은 복원력을 좌변으로 옮긴 부호이다.
