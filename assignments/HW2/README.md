## 실행

MATLAB에서 이 폴더를 현재 폴더로 지정한 후 `run_all`을 실행합니다. 각 문제의 결과 텍스트와 그래프 PNG, [검증 요약](validation.txt)이 생성됩니다. 기본 MATLAB만 사용합니다.

문제 7의 kg 표기, 문제 9의 외력 번호, 문제 13의 반올림 계수는 해당 풀이에서 원문과 해석을 구분했습니다.
