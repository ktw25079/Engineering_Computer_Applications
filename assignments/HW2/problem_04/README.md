# HW2 · 문제 04: 두 벡터의 사이각

## 문제

r1=[−2,6,5], r2=[5,−1,3]의 사이각을 acosd, cosd, sqrt, dot 등을 활용하여 degree로 구한다.

[원본 PDF 1쪽](../../EngComp_HW2.pdf#page=1)

## 풀이

cosθ=(r1·r2)/(|r1||r2|)에서 acosd로 각도를 계산한다. 부동소수점 반올림 때문에 코사인 입력이 [−1,1]을 미세하게 벗어나는 것을 막기 위해 범위를 제한한다.
