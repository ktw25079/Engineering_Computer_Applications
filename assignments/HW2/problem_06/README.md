# HW2 · 문제 06: 키르히호프 회로 전류

## 요구사항

V1=20 V, V2=12 V, V3=40 V, [R1,…,R8]=[18,10,16,6,15,8,12,14] Ω인 그림의 4개 시계방향 루프 전류 i1~i4를 Ax=b로 도출하여 구한다.

[원본 PDF 1쪽](../../EngComp_HW2.pdf#page=1)

## 해결 방법

공유 저항 R의 전압강하는 두 루프 전류의 차를 곱한 R(i_i−i_j)로 계산한다. 따라서 대각 원소는 각 루프의 저항 합, 비대각 원소는 공유 저항의 음수이다. 그림의 전압원 극성에 따라 b=[V1;0;−V2;V3]이다.

```math
A=\begin{bmatrix}44&-10&-16&0\\-10&43&-6&-12\\-16&-6&30&-8\\0&-12&-8&34\end{bmatrix}.
```

[제공된 방정식 해설](../../../solutions/HW2_Sol_eqn.pdf#page=1)과 각 루프 식을 대조한다. 음수 전류가 나오면 실제 방향이 가정 방향과 반대라는 뜻이다.

## 결과

시계방향 루프 전류는 **[0.841140, 0.720643, 0.612733, 1.574988] A**였다. KVL 최대 절대 잔차는 약 **5.33×10⁻¹⁵ V**였다.
