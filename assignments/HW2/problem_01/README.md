# HW2 · 문제 01: 벡터의 크기

## 요구사항

u=[23.5,−17,6]의 크기를 (a) sum과 sqrt를 이용한 요소별 연산, (b) norm으로 계산한다.

[원본 PDF 1쪽](../../EngComp_HW2.pdf#page=1)

## 해결 방법

유클리드 노름은 성분 제곱의 합의 제곱근이다. 제곱은 벡터에 대한 `.^2`를 사용한다.

## 결과

요소별 계산과 `norm` 모두 **29.61840644**를 반환했다.
