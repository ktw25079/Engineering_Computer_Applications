# HW2 · 문제 01: 벡터의 크기

## 문제

u=[23.5,−17,6]의 크기를 (a) sum과 sqrt를 이용한 요소별 연산, (b) norm으로 계산한다.

[원본 PDF 1쪽](../../EngComp_HW2.pdf#page=1)

## 풀이
