# HW2 · 문제 03: 벡터 삼중곱 항등식

## 문제

u=[−2,6,5], v=[5,−1,3], w=[4,7,−2]에 대해 u×(v×w)=v(u·w)−w(u·v)를 검증한다.

[원본 PDF 1쪽](../../EngComp_HW2.pdf#page=1)

## 풀이

안쪽 외적을 먼저 계산한 좌변과 내적 두 개를 이용한 우변을 독립적으로 계산한다. 결과는 [124,−17,70]이다.

## 실행과 결과

이 폴더에서 `main`을 실행합니다. 계산값은 `results`에 저장되고 검증 실패 시 `assert`가 오류를 발생시킵니다. 상위 폴더에서 `run_all`을 실행하면 결과 파일과 그래프가 갱신됩니다.
