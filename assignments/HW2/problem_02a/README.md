# HW2 · 문제 02a: 벡터 내적

## 요구사항

u=[−3,8,−2], v=[6.5,−5,−4]의 내적을 (a) sum과 요소별 곱, (b) 행벡터×열벡터, (c) dot으로 계산한다.

[원본 PDF 1쪽](../../EngComp_HW2.pdf#page=1)

## 해결 방법

내적은 대응 성분을 곱하여 더한 스칼라이다. 세 방법 모두 −51.5가 되어야 한다. 원문의 첫 번째 Problem 2이다.

## 결과

요소별 곱의 합, 행렬 곱, `dot`의 결과가 모두 **−51.5**로 일치했다.
