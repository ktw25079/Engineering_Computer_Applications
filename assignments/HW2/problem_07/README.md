# HW2 · 문제 07: 케이블 장력과 단위 해석

## 문제

L=120 m, h=50 m, x=[10,30,50,70,90,110] m, W=500 kg가 주어지고 T=WL sqrt(h²+x²)/(hx)로 제시되어 있다. 각 연결 위치의 장력을 구한다.

[원본 PDF 2쪽](../../EngComp_HW2.pdf#page=2)

## 풀이

장력 식의 W는 힘이어야 하나 원문은 kg로 표기한다. 원문대로 W=500을 넣은 수치와, 질량 500 kg을 g=9.81 m/s²로 중량으로 바꾼 SI 장력(N)을 함께 제시한다. 두 값을 혼동하지 않는다. 모멘트 평형 T·sinα·x=W·L에서 sinα=h/sqrt(h²+x²)를 대입한 식이다.
