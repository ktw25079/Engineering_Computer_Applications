# HW2 · 문제 05: 선형 연립방정식

## 문제

3x−2y+5z=7.5, −4.5x+2y+3z=5.5, 5x+y−2.5z=4.5의 해를 구한다.

[원본 PDF 1쪽](../../EngComp_HW2.pdf#page=1)

## 풀이

미지수를 [x;y;z]로 두고 각 행에 방정식 계수를 배치한다. `A\b`로 풀고 잔차 A·해−b를 확인한다.
