# HW2 · 문제 08: 2자유도 질량·강성행렬과 정적 변위

## 문제

벽−k1−m1−k2−m2−k3−벽 시스템에서 m1=m2=1 kg, k1=k2=k3=2 N/m이다. (a) M,K, (b) F=[1;2] N일 때 정적 평형 변위 x를 구한다.

[원본 PDF 2쪽](../../EngComp_HW2.pdf#page=2)

## 풀이

뉴턴 법칙으로 M·x¨+K·x=F이다. 첫 질량의 복원력은 −k1x1−k2(x1−x2), 두 번째는 −k2(x2−x1)−k3x2이다. 따라서 M=diag([1,1]), K=[4,−2;−2,4]이다. 정적 상태에서는 가속도가 0이므로 Kx=F를 푼다.
