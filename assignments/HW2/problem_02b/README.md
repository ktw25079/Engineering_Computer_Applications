# HW2 · 문제 02b: 요소별 역수·제곱·나눗셈

## 문제

v=[2,4,6,8,10]에서 (a) 각 성분의 역수, (b) 각 성분 제곱의 역수, (c) [1,2,3,4,5], (d) [1,1,1,1,1]을 도출한다.

[원본 PDF 1쪽](../../EngComp_HW2.pdf#page=1)

## 풀이

원문에서 두 번째로 인쇄된 Problem 2를 `problem_02b`로 보존했다. `1./v`, `1./v.^2`, `v/2`, `v./v`를 사용한다. 행렬 나눗셈 `/`와 요소별 나눗셈 `./`를 구분한다.

## 실행과 결과
