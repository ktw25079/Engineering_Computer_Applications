# HW3 · 외팔보 처짐과 2링크 로봇팔

외팔보 하중별 처짐을 계산하고 복합하중은 중첩해 풀었다. 2링크 로봇팔은 관절각을 말단 좌표로 변환해 궤적과 자세를 시각화했다. 각 문제에서 계산값과 그래프를 확인할 수 있다.

| 문제 | 내용 |
| --- | --- |
| [01](problem_01/README.md) | 집중하중에 의한 외팔보 처짐 |
| [02](problem_02/README.md) | 모멘트와 등분포하중 처짐 |
| [03](problem_03/README.md) | 복합하중 처짐의 중첩 |
| [04](problem_04/README.md) | 2링크 로봇팔 궤적과 자세 |

## 실행

MATLAB에서 이 폴더를 현재 폴더로 지정하고 `run_all`을 실행합니다. 각 문제의 `results.txt`와 그래프 PNG를 갱신하고 [검증 요약](validation.txt)을 저장합니다.
