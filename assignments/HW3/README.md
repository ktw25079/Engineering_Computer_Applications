## 실행

MATLAB에서 이 폴더를 현재 폴더로 지정하고 `run_all`을 실행합니다. 각 문제의 `results.txt`와 그래프 PNG를 갱신하고 [검증 요약](validation.txt)을 저장합니다.

네 문제의 PDF 조건을 사용했습니다. 수치 함수는 각 문제 폴더에 함께 있어 다른 문제를 먼저 실행할 필요가 없습니다.
