# HW1 · 문제 11: 행렬식 직접 계산과 det 비교

## 문제

A=[1 2;2 8], B=[3 4;5 7], C=[1 1 1;1 2 2;1 2 3], D=[1 1 2;0 0 0;1 0 2]의 행렬식을 (a) 배열 인덱싱을 이용한 직접식, (b) det 함수로 계산한다.

[원본 문제 PDF 2쪽](../../EngComp_HW1.pdf#page=2)의 조건을 정리했습니다.

## 풀이

2×2는 $ad-bc$, 3×3은 첫 행을 기준으로 여인수 전개한다. D는 영행을 포함하므로 행렬식이 0이다. 결과는 A=4, B=1, C=1, D=0이다.
