# HW1 · 문제 8: 행벡터와 열벡터 결합

## 문제

a=[7,2,−3,1,0], b=[−3,10,0,7,−2], c=[1,0,4,−6,5]를 정의한다. (a) 세 벡터가 행이 되는 3×5 행렬 A, (b) 세 벡터가 열이 되는 5×3 행렬 B를 만든다.

[원본 문제 PDF 2쪽](../../EngComp_HW1.pdf#page=2)의 조건을 정리했습니다.

## 풀이

세 행벡터를 세미콜론으로 이어 붙여 A를 만들고, 각 벡터를 비켤레 전치 `.'`하여 열로 결합한다. 입력이 실수이므로 켤레 전치 `'`도 같은 결과지만 일반적인 배열 전치의 의미를 명확히 한다.
