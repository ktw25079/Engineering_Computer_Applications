# HW1 · 문제 7: 규칙을 이용한 행렬 생성

## 요구사항

요소를 하나씩 나열하지 않고 (a) A의 행을 [0 5 … 30], [600 500 … 0], [0 0.8333 1.6667 2.5 3.3333 4.1667 5]로 만든다. (b) B의 열을 [1;2;3;4;5], 영벡터, 모두 3인 벡터로 만든다. (c) 3×5 영행렬의 (3,5) 성분만 8로 만든다.

## 해결 방법

(a)의 세 번째 행은 반올림된 표의 숫자를 입력하지 않고 `linspace(0,5,7)`로 생성한다. (b)는 `zeros`, `ones`와 열 결합, (c)는 영행렬 생성 후 인덱싱 대입을 사용한다.

## 결과

A는 **3×7**, B는 **5×3** 행렬로 생성했다. C는 **3×5**이며 `(3,5)=8`만 0이 아닌 원소다.
