# HW1 · 문제 13: 3×3 역행렬의 존재 여부

## 문제

문제 11의 C=[1 1 1;1 2 2;1 2 3], D=[1 1 2;0 0 0;1 0 2]에 대해 가능한 경우 inv로 역행렬을 구한다.

[원본 문제 PDF 2쪽](../../EngComp_HW1.pdf#page=2)의 조건을 정리했습니다.

## 풀이

C의 행렬식은 1이므로 역행렬이 존재한다. D는 영행을 포함하고 rank(D)=2<3이므로 역행렬이 없다. 특이행렬에 `inv`를 호출해 Inf/NaN을 답으로 기록하지 않는다. `pinv`는 다른 개념이므로 이 문제의 역행렬 답을 대체하지 않는다.
