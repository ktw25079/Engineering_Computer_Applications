# HW1 · 문제 6: 등간격 벡터 생성

## 문제

(a) 1부터 20까지 간격 1, (b) 0부터 2π까지 간격 π/10, (c) 4부터 20까지 같은 간격의 값 15개, (d) [1 2 … 10 9 … 1]을 한 줄로 생성한다. (d)의 요소를 하나씩 직접 입력하지 않는다.

[원본 문제 PDF 2쪽](../../EngComp_HW1.pdf#page=2)의 조건을 정리했습니다.

## 풀이

간격이 주어진 경우 콜론 연산자를, 개수가 주어진 경우 `linspace`를 사용한다. (d)는 증가·감소 구간을 이어 붙이며 정점 10을 중복하지 않는다.
