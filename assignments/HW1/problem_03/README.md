# HW1 · 문제 3: 배열로 도형 크기 계산

## 요구사항

(a) 원통 반지름 r=3, 높이 h=[1,5,12]에 대한 부피를 구한다. (b) 삼각형 밑변 b=[2,4,6], 높이 h=12에 대한 면적을 구한다. 원문은 길이 단위를 지정하지 않는다.

## 해결 방법

반지름과 삼각형 높이는 스칼라이다. 따라서 `pi*r^2*h`, `0.5*b*h`처럼 배열 전체에 스칼라를 곱하면 된다. 결과 단위는 각각 입력 길이 단위의 세제곱과 제곱이다.

## 결과

원통 부피는 약 **[28.2743, 141.3717, 339.2920]**, 삼각형 면적은 **[12, 24, 36]** 이었다. 단위는 각각 입력 길이 단위의 세제곱·제곱이다.
