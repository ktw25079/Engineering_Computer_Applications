# HW1 · 문제 1: 원과 구의 면적·부피

## 문제

(a) 반지름 5 cm인 원의 면적, (b) 반지름 10 cm인 구의 표면적, (c) 반지름 2 cm인 구의 부피를 구한다.

[원본 문제 PDF 1쪽](../../EngComp_HW1.pdf#page=1)의 조건을 정리했습니다.

## 풀이

각각 $A=\pi r^2$, $S=4\pi r^2$, $V=4\pi r^3/3$을 사용한다. 면적은 cm², 부피는 cm³이다. 세 문항의 반지름은 서로 다르다.
