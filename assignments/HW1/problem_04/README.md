# HW1 · 문제 4: RLC 회로의 특성근

## 요구사항

L=100 mH, C=1 μF에 대해 S=−R/(2L)±sqrt((R/(2L))²−1/(LC))를 구한다. (a) R=800 Ω, (b) R=100:100:1000 Ω의 두 근을 계산한다.

## 해결 방법

L=0.1 H, C=10⁻⁶ F로 변환한다. R이 벡터이므로 제곱은 `.^2`이다. 판별식이 음수이면 MATLAB의 `sqrt`가 켤레복소수 근을 계산한다. 임계 저항은 $2\sqrt{L/C}\approx632.456\,\Omega$이다. 두 근을 특성방정식 $S^2+(R/L)S+1/(LC)=0$에 대입해 확인한다.

## 결과

R=800 Ω에서 특성근은 **−1550.5103 s⁻¹, −6449.4897 s⁻¹**이었다. 임계 저항은 약 **632.4555 Ω**이며 이보다 작은 표본에서는 켤레복소수 근을 얻었다.
