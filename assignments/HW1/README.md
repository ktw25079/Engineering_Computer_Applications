## 실행

MATLAB에서 이 폴더를 현재 폴더로 선택하고 `run_all`을 실행합니다. 각 문제의 `results.txt`와 [실행 요약](validation.txt)이 갱신됩니다. 기본 MATLAB만 사용합니다.

문제 5의 최대 높이 인쇄식에는 차원 오류가 있어 원문 식의 계산값과 물리적으로 수정한 값을 별도로 제공합니다.
