# 과제 문제와 MATLAB 풀이

행렬·역학·수치해석 37문제를 MATLAB으로 풀고, 공학 프로그래밍 활용 사례를 1쪽 보고서로 정리했습니다. 아래에서 문제별 해결 방법과 결과를 확인할 수 있습니다.

| 과제 | 문제별 풀이 | 주요 내용 |
| --- | --- | --- |
| HW1 | [13문제](HW1/README.md) | 기초 계산·배열·행렬식·역행렬 |
| HW2 | [14문제](HW2/README.md) | 벡터·회로·질량–스프링·그래프 |
| HW3 | [4문제](HW3/README.md) | 외팔보 처짐·2링크 로봇팔 |
| HW4 | [통합 1문제](HW4/README.md) | n-Link 클래스와 애니메이션 |
| HW5 | [5문제](HW5/README.md) | 보간·미분·적분·미분방정식 |
| HW6 | [조사 1문제](HW6/README.md) | 공학 프로그래밍 활용 보고서 |

각 문제 폴더의 README에서 요구사항·해결 방법·결과를 읽고, `main.m`과 `results.txt`로 코드 및 실제 실행 결과를 확인할 수 있습니다. 그래프와 GIF가 필요한 문제에는 해당 결과 파일을 함께 두었습니다. HW6은 코드가 아닌 보고서 과제입니다.

MATLAB에서 저장소 루트를 현재 폴더로 선택하고 [run_homework](../run_homework.m)를 실행하면 HW1–HW5의 계산과 검증을 차례로 수행합니다.
