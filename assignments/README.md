# MATLAB 공학 계산 · 과제별 풀이와 결과

수업 과제의 조건을 바탕으로 MATLAB 풀이 37개를 재구현했습니다. 각 문제에서 사용한 식과 가정을 코드·실행 결과와 함께 확인할 수 있습니다.

- **로봇팔 운동학** — 링크 끝점을 다음 관절의 시작점으로 연결해 3링크 로봇팔 끝점의 궤적을 계산했습니다. 5초 동안 0.01초 간격으로 계산한 자세를 애니메이션으로 확인할 수 있습니다. [구현과 궤적](HW4/problem_01/README.md) · [애니메이션](HW4/problem_01/Result.gif)
- **수치미분 검증** — 다항함수의 도함수를 차분으로 근사하고 해석해와 비교했습니다. 같은 구간에서 격자 간격을 0.1에서 0.05로 줄이자 최대 절대오차가 0.24에서 0.06으로 줄었습니다. [계산식과 오차 그래프](HW5/problem_02/README.md)
