# HW5 · 문제 03: integral과 trapz의 적분 비교

## 문제

y=5x³−2x²+3을 x=−1부터 1까지 integral, trapz로 각각 적분하여 출력한다. trapz의 간격은 임의로 정한다.

[원본 PDF 1쪽](../../HW5.pdf#page=1)

## 풀이

적응형 적분 integral에는 함수 핸들을, trapz에는 좌표와 샘플값을 준다. trapz 간격은 0.001로 정했다. 홀함수인 5x³은 대칭 구간에서 적분이 0이므로 정확한 적분값은 14/3이다. 간격을 절반으로 줄여 오차 감소도 확인한다.
