# HW5 · 보간·수치미분·적분·미분방정식

[원본 과제](../HW5.pdf)

보간·미분·적분·미분방정식 5문제를 MATLAB으로 풀고 해석해 또는 간격 수렴으로 오차를 확인했다. 수치미분은 간격을 절반으로 줄였을 때 최대오차가 0.24에서 0.06으로 감소했다.

| 문제 | 내용 |
| --- | --- |
| [01](problem_01/README.md) | 압력·부피 데이터 보간 |
| [02](problem_02/README.md) | 다항함수의 수치미분 |
| [03](problem_03/README.md) | integral과 trapz의 적분 비교 |
| [04](problem_04/README.md) | 1차 미분방정식의 ode45 해 |
| [05](problem_05/README.md) | 질량–스프링 자유진동 |

## 실행

MATLAB에서 이 폴더를 현재 폴더로 지정하고 `run_all`을 실행합니다. 각 문제의 `results.txt`와 그래프 PNG를 갱신하고 [검증 요약](validation.txt)을 저장합니다.

문제 1의 부피 단위 오기와 문제 5의 초기 속도 누락을 각 문제 풀이에 명시했습니다. 코드의 수치 결과는 해석해·보간 데이터·간격 수렴으로 확인합니다.
